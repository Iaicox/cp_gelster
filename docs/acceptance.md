# Ручная приёмка: чек-лист

Для Ильи перед переводом в done и перед удалением `legacy/`. Каждый пункт: **действие** → ожидаемый результат.
Отметка `[x]` — проверено, рядом можно дописать браузер и замечание. Автоматически уже проверено
(`tests/run.sh`, `npm run e2e`): разбор страниц на фикстурах, расчёты, хранилище, печать в PDF в Chromium
без колонтитулов, полный путь форма → КП → PDF → DOCX → экспорт → удаление → импорт. Здесь — то, что видно
только глазами, в настоящих браузерах, в Word и на настоящем сервере.

**Подготовка.** Собрать (`npm run build`) и запустить (`npm start` или хостинг), открыть в Chrome. Рядом открыть
старую версию и сравнить с ней и с примерами из `Примеры готового КП/`. Нужны ссылки на коллекцию с обоих сайтов:
`https://gelster.ru/marmoleum_cocoa.htm` и `https://ooogelingen.ru/m_cocoa.htm`.

## 2. Печать в PDF в настоящем диалоге
- [x] **Chrome: «Сохранить в PDF» → «Сохранить как PDF», «Поля» = «По умолчанию», «Колонтитулы» включены.** → В превью диалога и в файле нет даты, адреса, заголовка и номеров страниц; число листов = число листов предпросмотра; шапка и подпись на каждом листе; кнопок и предупреждений нет; имя файла `КП_<компания>_от_дд.мм.гг`.
- [x] **Edge: то же самое.** → То же самое.
- [ ] **В Chrome поставить «Поля» = «Обычные».** → Колонтитулы браузера появились (известная оговорка); вернуть «По умолчанию» → пропали. Подсказка у кнопки говорит, что делать.

## 3. DOCX в Word
На `srv` нет ни Word, ни LibreOffice: открытие файла проверено только разбором XML. Эти пункты — главные.
- [x] **«Сохранить в DOCX».** → Скачался `КП_<компания>_от_дд.мм.гг.docx` (около 2 МБ).
- [x] **Открыть в Word.** → Открывается без предупреждений («нечитаемое содержимое», «восстановить»), без «защищённого просмотра» сверх обычного для скачанных файлов.
- [x] **Посмотреть шрифт текста (Главная → Шрифт) на компьютере, где PT Serif не установлен.** → PT Serif 11,5 (шрифт из файла). Если Word предупредил о файле или шрифт подменился — записать: решение откатывается на ссылку по имени (см. `decisions.md`, «DOCX: шрифты»).
- [x] **Шапка и подпись.** → На каждой странице сверху шапка «Гельстер» на всю ширину листа, снизу подпись менеджера; текст на них не наезжает.
- [x] **Главное фото.** → Слева от первого абзаца описания, текст обтекает справа. Дописать в этот абзац 3–4 строки → фото едет вместе с абзацем, не наезжает на текст. Если ведёт себя плохо — записать (вариант «отдельным абзацем» готов).
- [x] **Правка абзаца.** → Абзац правится обычным набором; стиль абзаца «КП Текст» (в коллекции стилей).
- [x] **Правка пункта списка, Enter в конце пункта.** → Появился новый пункт того же списка с маркером/номером Word.
- [x] **Правка ячейки таблицы (цена, количество, наименование).** → Число — обычный текст, правится; строка не разрывается между страницами; при переносе таблицы на новую страницу шапка повторяется.
- [ ] **Изменить стиль «КП Текст» (например, кегль 12).** → Меняется весь текст описания разом.
- [ ] **Открыть тот же файл в LibreOffice Writer (если есть).** → Открывается, таблицы, списки, колонтитулы на месте.

## 5. Экспорт и импорт
- [x] **«Экспорт проекта».** → Скачался `gelster-kp_<компания>_<дата>.json`.
- [x] **«Экспорт всех проектов».** → Скачался `gelster-kp_все_<дата>.json`.
- [x] **Удалить проект, «Импорт из файла» с файлом экспорта.** → Проект вернулся с правками КП, выбранными артикулами и картинками (КП открывается без сети).
- [x] **Импорт того же файла при существующем проекте.** → Вопрос «Проекты уже есть» с выбором; «Отмена» ничего не меняет.
- [ ] **Импорт в другом браузере или на другом компьютере.** → Проект открывается полностью.
- [x] **Импорт испорченного файла (любой .json).** → Сообщение об ошибке, данные не изменились.

## 6. Установка на хостинг
- [ ] **Загрузить содержимое `dist/` в каталог сайта по README, создать `config.php` и пароль.** → Сайт открывается по своему адресу (в том числе из подкаталога).
- [ ] **Открыть `api/health.php`.** → JSON с `"ok": true`, `phpOk`, `curl`, `dataWritable` — `true`, `passwordSet` — `true`.
- [ ] **На хостинге создать КП по ссылкам с обоих сайтов.** → Страница коллекции и картинки загружаются (прокси работает), курс ЦБ загружается кнопкой «ЦБ».
- [ ] **Обновить сборку по README (перезалить `dist/`).** → Менеджеры, подписи и пароль сохранились.
