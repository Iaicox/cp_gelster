# Оформление интерфейса (не листа КП)

Правила для формы, списка проектов, панели страницы КП, окна артикулов и страницы менеджеров. Метод — skill
`unslop` из харнесса (`claude/skills/unslop/SKILL.md`, автор Damir Sokolovsky, CC BY 4.0): сначала направление,
затем проходы «отступы → цвет → значки → тексты → шрифт → раскладка → детали → движение». Исполнитель читает skill
и его `references/design-values.md` перед работой. Направление ниже согласовано задачей 7d44eec9 — шаг skill
«показать направление и ждать ответа» пропускается.

**Граница.** Лист КП (всё внутри страницы A4 в предпросмотре, PDF и DOCX) не меняется никогда:
`src/styles/document.css` и компоненты листа не правятся. Элементы управления поверх листа не печатаются.

## Направление

- **Продукт.** Рабочий инструмент менеджера Gelster: за несколько минут собрать КП на напольное покрытие.
- **Характер.** Деловой, плотный, спокойный.
- **Мир.** Фирменный бланк и смета: бумага, типографская линейка, образцы покрытий.
- **Яркое место.** Сам лист КП в предпросмотре и образцы артикулов в окне выбора. Больше цвета нигде нет.
- **Подпись.** Золотая линия бланка (2 px) отмечает текущее: выбранный проект в списке, выбранную коллекцию
  в панели. Только это, не декор.

## Правила

- **Шрифт.** PT Sans из `public/fonts` (он уже в бланке). Размеры 13 / 15 / 18 / 24, начертания 400 и 700 (других
  в комплекте нет; 700 — только заголовок страницы и итоговые числа). Числа — `font-variant-numeric: tabular-nums`,
  в таблицах выровнены вправо, формат `1 234,56` везде.
- **Цвет.** Одна нейтральная шкала, слегка тёплая: фон `#f6f5f2`, поверхность `#ffffff`, линии — цвет текста
  с прозрачностью 10 %, текст `#1f211f` / `#5c605b` / `#8a8e88`. Один акцент — серо-зелёный знака Gelster `#4f5d4c`
  (главная кнопка, фокус). Золото `#c9a227` — только «подпись». Ошибка `#b02a37`, предупреждение — текстом
  на поверхности `#fbf3dc`. Тёмной темы нет.
- **Отступы.** Сетка 4 px. Поля ввода и кнопки высотой 36, строки списка проектов 52 (две строки текста),
  разделы формы разделены 32, внутри раздела 12. Одинаковое — одинакового размера.
- **Поверхности.** Без градиентов, свечения, цветных теней, стекла. Радиус: поля и кнопки 6, панели и окна 10.
  Разделы формы — заголовок и линия, не карточки с тенью.
- **Кнопки.** Одна главная на экран («Создать КП»; «Сохранить в PDF»); остальные — тихие с линией. Удаление —
  тихая кнопка, красной становится при наведении.
- **Значки.** `lucide-react`, 16 px, штрих 1,5, цвет текста. Значок без подписи — только с `aria-label` и `title`
  (стрелки порядка, «×», «+»). Эмодзи нет.
- **Тексты.** Без восклицательных знаков и точек в кнопках, подписях и заголовках; с маленькой буквы после первой
  («Создать копию», «Сохранить копию»). Заголовок формы — название текущего проекта, а не «Заполните форму КП».
  Сообщение об ошибке говорит, что сделать.
- **Состояния.** У каждого элемента есть наведение и видимый фокус с клавиатуры (обводка акцентом 2 px). Поле
  с ошибкой — красная линия и текст под полем. Пустые состояния текстом («Проектов пока нет»).
- **Движение.** Только смена цвета за 120 мс. Ничего не пульсирует и не въезжает.
- **Раскладка.** Форма на всё окно: панель проектов 280 px, содержимое до 960 px; нижняя полоса с суммой
  прилипает. Панель страницы КП прилипает сверху, в две строки: действия с документом; действия с коллекцией.

ещё не делалась», «Сохраняем…», «Сохранено», «Отменить», «Вернуть», «Артикулы», «Номер артикула», «Выбрано: 5»,
«Только выбранные», «Скидка, %», «Показать НДС отдельной строкой», «Условия и комментарии», «Своя фраза»,
