# Правила стека (для исполнителей)

Полное решение — `docs/spec.md`. Здесь только то, что нужно помнить при каждой правке.

## Общее
- TypeScript strict, один `package.json`, Node ≥ 22. Команды: `npm run dev | build | start | test | lint | typecheck | e2e`.
- Каталоги: `shared/` (без DOM и Node API), `server/`, `src/` (клиент), `public/`, `data/`, `legacy/` (не править).
- Типы данных и ответы API описываются zod-схемами в `shared/schema.ts`; типы выводятся из схем, не дублируются.
- Новые зависимости — только если без них нельзя; каждая упоминается в `docs/decisions.md` одной строкой.
- Код и коммиты по-английски, тексты интерфейса по-русски.

## Клиент
- React 19, функциональные компоненты, react-router. Без jQuery, Bootstrap, CSS-фреймворков и библиотек состояния.
- Стили — обычный CSS: `src/styles/document.css` (страницы КП, размеры в мм/pt, перенос из `style/style.css`
  без изменения значений) и `form.css`. Размеры КП не «улучшать».
- Любой HTML с сайта или из `contenteditable` проходит DOMPurify с белым списком из спеки перед вставкой в DOM
  и перед сохранением. `dangerouslySetInnerHTML` — только с очищенной строкой.
- Проекты читаются и пишутся только через `src/storage/projects.ts`.
- Расчёты денег — только функции из `shared/calc.ts`.
- Логика разбивки на страницы и построения модели — чистые функции, отделённые от React.

## Сервер
- Hono на `@hono/node-server`. По умолчанию слушает `127.0.0.1`.
- Наружу по адресу от клиента сервер ходит только через `server/fetch-allowed.ts` (белый список хостов, https,
  ручные редиректы, таймаут, лимит размера). Прямой `fetch(req.query.url)` запрещён. Проверку TLS не отключать.
- Имена файлов от пользователя не используются; тип загружаемого файла проверяется по сигнатуре.
- Ошибки — `{ error: string }` с человеческим текстом по-русски и осмысленным статусом.
- Секретов в репозитории нет; настройки — переменные окружения (`PORT`, `HOST`, `DATA_DIR`, `ALLOWED_HOSTS`, `ADMIN_TOKEN`).

## Тесты
- Vitest. Парсер тестируется на сохранённых страницах в `server/__fixtures__/`; сеть в тестах не используется.
- Тесты не ослаблять ради зелёного прогона. Изменилась вёрстка сайта — обновить фикстуру отдельным коммитом.
