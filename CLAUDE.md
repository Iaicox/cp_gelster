# gelster-cp

Генератор коммерческих предложений Gelster: форма запроса и страница КП с выгрузкой в PDF и DOCX.
Переписывается с PHP + jQuery на React + TypeScript; старая версия лежит в корне (после каркаса — в `legacy/`).

Этот файл — оглавление для агента: коротко, только то, чего нельзя узнать из `ls` и чтения кода.

## Где что лежит
- `docs/spec.md` — что строим и как. Источник истины для исполнителя.
- `docs/decisions.md` — принятые решения с датами и причинами.
- `docs/context/stack.md` — правила стека.
- Команды запуска и тестов — в `README.md` (появляется с каркасом); единая точка тестов `tests/run.sh`.

## Правила
- Работа идёт в ветках `task/<id>`, в основную ветку сливает только Илья переводом карточки в done.
- Новое поведение покрывается тестом, подключённым к `tests/run.sh`.
- Секреты только вне репозитория (`~/.config/gelster-cp/.env`), не в коде и не в `docs/`.
